# ReturnIQ: Production Case Study & Evaluation Dossier

## Executive summary
ReturnIQ is an AI returns-intelligence concept for e-commerce teams. It categorizes customer return comments, highlights recurring root causes, links issues to potential margin impact, and supports mitigation experiments.

## Evaluation snapshot
The supplied project materials report:
- Golden-set accuracy: 95.0% across 100 labeled test cases
- Macro F1 score: 0.952
- Regression quality gate: 35/35 suites passing, reported score 96.4%
- Human correction baseline: 2.8% for low-confidence triage
- Experiment: reported -10.7% return-rate delta

These are project-reported figures; interpret them in the context of the evaluation method and evidence included with the project.
