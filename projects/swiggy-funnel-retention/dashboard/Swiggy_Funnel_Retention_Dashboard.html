Opportunity 01

Reduce cart abandonment

Audit delivery fees, minimum order thresholds, ETA changes, and coupon clarity before payment.

Opportunity 02

Improve checkout confidence

Make the final payable amount and delivery estimate visible early; measure checkout completion.

Opportunity 03

Build repeat behaviour

Test relevant reorder reminders and saved favourites; evaluate 30-day repeat rate and opt-outs.

Measurement plan

Track each funnel step by acquisition channel, new vs returning customer, platform, and time period. Define the event schema first, validate instrumentation, then compare experiment cohorts against a baseline.

Suggested events: app_opened → restaurant_viewed → item_added → checkout_started → order_placed → repeat_order_placed.
